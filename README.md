# minipigGPTpet
A GPT pet of mini pig

## Install Pip mini pig pet

1. Close or restart Codex after copying the files.
2. Choose `Pip` folders above.
3. Copy the chosen `Pip` folder to `%USERPROFILE%\.codex\pets\Pip` on Windows.
4. In Codex, open **Settings → Pets**, select **Refresh**, then choose **Pip**.

The pet uses a validated transparent 1536 × 2288 WebP spritesheet (`spriteVersionNumber: 2`).
